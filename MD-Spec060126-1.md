Section 1: Executive & System Architecture Overview
1.1 Project Intent & Scope
ArchivalMind AI (internally designated as the Agenta Orchestrator v2.4 Pro Suite) is an advanced, full-stack, institutional-grade documentation forensic audit and code intelligence platform. It is engineered to ingest compressed file systems (specifically, directory hierarchies wrapped in standard PKWare ZIP compression format), decompress the file structures on-the-fly, extract physical file volumes, run targeted server-side text extraction on structured assets such as Adobe PDFs, and submit the compiled context corpus into a highly optimized, schema-compliant Large Language Model (Gemini 3.5 Flash) to generate multi-dimensional system audits.
The platform bridges the gap between raw binary files and structured semantic intelligence, resolving dependencies, identifying hidden architectural/security gaps, mapping logical relations into an interactive node-link network visualization, compiling a matrix of registered system entities, and designing a challenge-oriented diagnostic audit checklist.

1.2 Architectural Paradigm
The system utilizes a modern full-stack single-page application (SPA) architecture combined with a high-performance Express server written in native TypeScript.
Host Environment: The application runs behind an Nginx reverse-proxy layer on Linux container environments (Google Cloud Run / Sandbox), rigidly bound to local port 3000 on the network host 0.0.0.0.
Frontend Client Layer: Built with React 18, Vite, and Tailwind CSS. The interface is optimized to manage density, providing micro-animations and smooth transitions between core workspaces via standard browser runtime engines.
Backend Middleware Layer: A custom Express server serving dynamic endpoints. The same process switches dynamically between a Vite Node development server mode (injecting hot-reload assets) and a static production pipeline serving built physical production bundles from dist/ directly.
Intelligent Synthesizer Layer: Powered by the modern @google/genai TypeScript SDK executing server-side transactions with the gemini-3.5-flash model. The integration utilizes system prompts, low temperature settings (0.15), and response schemas (responseSchema) to enforce a type-safe JSON schema output.
Section 2: Core Capabilities & Functional Boundaries
2.1 Multi-Format File Ingestion
The Agenta Orchestrator supports three distinct classes of data ingestion:
Local Binary ZIP Archive Drag-and-Drop / Browser Selection: Allows users to drop a multi-directory ZIP containing legacy scripts, PDFs, READMEs, YAML configurations, etc.
Google Drive Cloud Access: Handles Google Drive file sharing paths (such as viewer links containing document IDs) by translating them and fetching file streams directly via server-side download handlers.

const renderMarkdownText = (mdText: string) => {
  if (!mdText) return <div className="text-slate-400 italic font-sans text-xs">No analysis files parsed yet.</div>;
  
  const lines = mdText.split('\n');
  let inTable = false;
  let tableHeaders: string[] = [];
  let tableRows: string[][] = [];

  return (
    <div className="space-y-4 text-slate-700 leading-relaxed font-sans max-w-none">
      {lines.map((line, idx) => {
        const trimmed = line.trim();

        if (trimmed.startsWith('```')) {
          return null; // Strip raw enclosure boundary tokens
        }

        // Process markdown tables dynamically
        if (trimmed.startsWith('|')) {
          inTable = true;
          const cells = trimmed
            .split('|')
            .map(c => c.trim())
            .filter((c, i, arr) => i > 0 && i < arr.length - 1);
          
          if (trimmed.includes('---')) {
            return null; // Ignore header alignment rules
          }

          if (tableHeaders.length === 0) {
            tableHeaders = cells;
            return null;
          } else {
            tableRows.push(cells);
            const nextLine = lines[idx + 1]?.trim();
            if (!nextLine || !nextLine.startsWith('|')) {
              const head = tableHeaders;
              const rows = [...tableRows];
              tableHeaders = [];
              tableRows = [];
              inTable = false;
              
              return (
                <div key={`table_${idx}`} className="overflow-x-auto my-5 border border-slate-200 rounded-xl overflow-hidden shadow-xs">
                  <table className="min-w-full divide-y divide-slate-200">
                    <thead className="bg-[#f8fafc]">
                      <tr>
                        {head.map((h, i) => (
                          <th key={i} className="px-5 py-3 text-left text-xs font-bold text-slate-650 uppercase tracking-wider font-display">
                            {h}
                          </th>
                        ))}
                      </tr>
                    </thead>
                    <tbody className="bg-white divide-y divide-slate-100 text-xs">
                      {rows.map((row, rowIdx) => (
                        <tr key={rowIdx} className="hover:bg-slate-50/50 transition-colors">
                          {row.map((cell, cellIdx) => (
                            <td key={cellIdx} className="px-5 py-3.5 text-slate-600 font-sans whitespace-pre-wrap leading-relaxed">
                              {cell}
                            </td>
                          ))}
                        </tr>
                      ))}
                    </tbody>
                  </table>
                </div>
              );
            }
            return null;
          }
        }

        // Inline mapping of headers, headings, lists, variables
        if (trimmed.startsWith('# ')) {
          return (
            <h1 key={idx} className="text-xl md:text-2xl font-bold font-display text-slate-900 tracking-tight pt-5 pb-1 border-b border-slate-100 flex items-center gap-2">
              <Sparkles className="w-5 h-5 text-indigo-650 shrink-0" />
              {line.substring(2)}
            </h1>
          );
        }

        if (trimmed.startsWith('## ')) {
          return (
            <h2 key={idx} className="text-lg md:text-xl font-bold font-display text-slate-900 tracking-tight pt-4 pb-1 border-b border-slate-100">
              {line.substring(3)}
            </h2>
          );
        }

        if (trimmed.startsWith('### ')) {
          return (
            <h3 key={idx} className="text-base font-bold font-sans text-slate-850 tracking-tight pt-3">
              {line.substring(4)}
            </h3>
          );
        }

        if (trimmed.startsWith('- ') || trimmed.startsWith('* ')) {
          const rawContent = trimmed.substring(2);
          const boldMatch = rawContent.match(/\*\*(.*?)\*\*(.*)/);
          return (
            <ul key={idx} className="list-disc list-inside pl-5 space-y-1 my-1">
              <li className="text-xs text-slate-600 font-sans leading-relaxed">
                {boldMatch ? (
                  <>
                    <strong className="text-slate-900 font-semibold">{boldMatch[1]}</strong>
                    {boldMatch[2]}
                  </>
                ) : rawContent}
              </li>
            </ul>
          );
        }

        const numMatch = trimmed.match(/^(\d+)\.\s(.*)/);
        if (numMatch) {
          const num = numMatch[1];
          const rawContent = numMatch[2];
          const boldMatch = rawContent.match(/\*\*(.*?)\*\*(.*)/);
          return (
            <div key={idx} className="flex gap-3 items-start pl-3 py-1 my-1">
              <span className="flex items-center justify-center bg-indigo-50 text-indigo-700 font-mono text-[10px] font-bold w-5 h-5 rounded shrink-0">

                    {boldMatch[2]}
                  </>

        return (

4.1 Dependency Link Relation Graph (components/NetworkGraph.tsx)

import React, { useState, useEffect } from 'react';
import { GraphNode, GraphEdge } from '../types';

interface NetworkGraphProps {
  data: {
    nodes: GraphNode[];
    edges: GraphEdge[];
  };
}

export default function NetworkGraph({ data }: NetworkGraphProps) {
  const [nodes, setNodes] = useState<(GraphNode & { x: number; y: number })[]>([]);
  const [selectedNode, setSelectedNode] = useState<(GraphNode & { x: number; y: number }) | null>(null);
  const [draggedNode, setDraggedNode] = useState<string | null>(null);

  // Generate initial coordinated layout using circular dispersion logic
  useEffect(() => {
    const width = 640;
    const height = 400;
    const center = { x: width / 2, y: height / 2 };
    const radius = 130;

    const positioned = data.nodes.map((node, index) => {
      const angle = (index / data.nodes.length) * 2 * Math.PI;
      return {
        ...node,
        x: center.x + radius * Math.cos(angle) + (Math.random() - 0.5) * 30,
        y: center.y + radius * Math.sin(angle) + (Math.random() - 0.5) * 30,
      };
    });

    setNodes(positioned);
  }, [data]);

  // Handle manual coordinate displacement (drag mechanics)
  const handleMouseMove = (e: React.MouseEvent<SVGSVGElement>) => {
    if (!draggedNode) return;
    const rect = e.currentTarget.getBoundingClientRect();
    const x = e.clientX - rect.left;
    const y = e.clientY - rect.top;

    setNodes(prev =>
      prev.map(n => (n.id === draggedNode ? { ...n, x: Math.max(20, Math.min(620, x)), y: Math.max(20, Math.min(380, y)) } : n))
    );
  };

  return (
    <div className="w-full h-full flex flex-col">
      <svg 
        className="w-full h-[400px] bg-slate-900 rounded-2xl border border-slate-800 shadow-inner cursor-grab select-none overflow-hidden"
        onMouseMove={handleMouseMove}
        onMouseUp={() => setDraggedNode(null)}
        onMouseLeave={() => setDraggedNode(null)}
      >
        {/* Render Vector Connector Lines */}
        {data.edges.map((edge, idx) => {
          const sourceNode = nodes.find(n => n.id === edge.source);
          const targetNode = nodes.find(n => n.id === edge.target);

          if (!sourceNode || !targetNode) return null;

          return (
            <g key={idx} className="opacity-70 hover:opacity-100 transition-opacity">
              <line
                x1={sourceNode.x}
                y1={sourceNode.y}
                x2={targetNode.x}
                y2={targetNode.y}
                stroke="#6366f1"
                strokeWidth={1.5}
                strokeDasharray="4 2"
              />
              <text
                x={(sourceNode.x + targetNode.x) / 2}
                y={(sourceNode.y + targetNode.y) / 2 - 4}
                className="fill-slate-400 font-mono text-[8px] font-semibold text-center"
                textAnchor="middle"
              >
                {edge.relationship}
              </text>
            </g>
          );
        })}

        {/* Render Entity Nodes */}
        {nodes.map(node => {
          const isSelected = selectedNode?.id === node.id;
          const isCoreFile = node.group === 'file';

          return (
            <g
              key={node.id}
              transform={`translate(${node.x},${node.y})`}
              className="cursor-pointer"
              onMouseDown={() => setDraggedNode(node.id)}
              onClick={(e) => {
                e.stopPropagation();
                setSelectedNode(node);
              }}
            >
              <circle
                r={isCoreFile ? 14 : 10}
                className={`${
                  isSelected
                    ? 'fill-indigo-500 stroke-white stroke-2'
                    : isCoreFile
                    ? 'fill-indigo-950 stroke-indigo-400'
                    : 'fill-slate-800 stroke-slate-500'
                } transition-all duration-150`}
              />
              <text
                dy={24}
                textAnchor="middle"
                className="fill-slate-200 font-sans text-[10px] font-bold select-none text-shadow"
              >
                {node.label}
              </text>
            </g>
          );
        })}
      </svg>
    </div>
  );
}

// API Endpoint: Extraction patterns using pdf-parse parameters
app.post('/api/pdf/extract-text', async (req, res) => {
  try {
    const { base64Data, filename } = req.body;
    if (!base64Data) {
      return res.status(400).json({ error: 'Missing base64Data' });
    }

    const pdfBuffer = Buffer.from(base64Data, 'base64');
    
    // Passing max: 5 guarantees we parse at most the first 5 pages of the document
    const parsed = await pdf(pdfBuffer, { max: 5 });
    
    const textLength = parsed.text ? parsed.text.trim().length : 0;
    const totalPages = parsed.numpages || 1;
    const isTrimmed = totalPages > 5;
    
    res.json({
      success: true,
      filename,
      text: parsed.text || '',
      totalPages,
      isTrimmed,
      message: isTrimmed 
        ? `Trimmed PDF to first 5 pages of ${totalPages} pages.`
        : `Read complete PDF (${totalPages} pages).`
    });
  } catch (error: any) {
    console.error('Error parsing PDF:', error);

app.post('/api/drive/download', async (req, res) => {
  try {
    const { urlOrId } = req.body;
    if (!urlOrId) {
      return res.status(400).json({ error: 'Missing URL or File ID' });
    }

    // Capture IDs securely across browser URLs
    let fileId = urlOrId.trim();
    if (fileId.includes('drive.google.com')) {
      const match = fileId.match(/\/file\/d\/([a-zA-Z0-9_-]+)/) || 
                    fileId.match(/id=([a-zA-Z0-9_-]+)/);
      if (match && match[1]) {
        fileId = match[1];
      }
    }

    console.log(`Requesting Google Drive Export File: ${fileId}`);
    
    const downloadUrl = `https://docs.google.com/uc?export=download&id=${fileId}`;
    const driveRes = await fetch(downloadUrl);
    
    if (!driveRes.ok) {
      throw new Error(`Google Drive returned status ${driveRes.status}. Make sure sharing permissions are configured appropriately.`);
    }

    const arrayBuffer = await driveRes.arrayBuffer();
    const buffer = Buffer.from(arrayBuffer);
    const base64 = buffer.toString('base64');
    
    res.json({
      success: true,
      fileId,
      base64,
      filename: `drive_file_${fileId}.zip`
    });
  } catch (error: any) {
    console.error('Error in Google Drive downloader:', error);
    res.status(500).json({ 
      error: 'Google Drive file access failed.', 
      details: error?.message || 'Check connection settings.' 
    });
  }
});

            }
          },
          required: ['executiveSummary', 'entities', 'gapAnalysis', 'graphData', 'followUpQuestions']
        }
      }
    });

    const outputText = response.text;
    if (!outputText) {
      throw new Error('Gemini API returned empty output stream');
    }

    res.json(summaryJSON);
  } catch (error: any) {
    console.error('Error preparing summary:', error);
    res.status(500).json({ 
      error: 'Executive synthesis failed', 
      details: error?.message || String(error) 
    });
  }
});
